# Database logos

The marks of the databases, shown beside connections to tell their kind.

- `postgres.svg`: PostgreSQL
- `mysql.svg`: MySQL

The files are the single-color versions from [Simple Icons](https://simpleicons.org) 16.38.1, whose icon files are released under CC0-1.0.
The logos themselves are trademarks of their owners: PostgreSQL of the PostgreSQL Community Association of Canada, MySQL of Oracle and its affiliates.
They are used here only to name the database a connection goes to.
